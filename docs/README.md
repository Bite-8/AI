# docs

このディレクトリは、AI実験プロジェクトの設計メモ、実装記録、学習ログをまとめる場所です。

コードだけでは追いにくい「何を作るのか」「なぜその設計にしたのか」「実装して何が分かったのか」を、Markごとに残します。

## 基本方針

### `mark{number}`
- Markごとにディレクトリを分ける
- 計画、実装メモ、実行結果、振り返りを同じMarkの中にまとめる

### `memo/`

整理前のメモや作業中の考えを置きます。

`memo/` の内容は正式な仕様や設計とは限りません。確定した内容は、対応する `mark{number}/` 配下のREADME、計画書、実装メモへ移します。
