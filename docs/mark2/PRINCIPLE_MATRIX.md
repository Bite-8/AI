## 仮説の昇格条件

実験候補へ進めるには、少なくとも以下を満たす。

1. 一次文献から観察事実と適用範囲を説明できる。
2. baseline内の既存の対応物をコードレベルで確認している。
3. 変更箇所と独立変数を一つに限定できる。
4. 改善予測と同時に、棄却する数値条件を事前登録できる。
5. 追加計算コストを含めた比較が可能である。
